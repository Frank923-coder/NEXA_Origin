Guía de funcionalidades del panel NEXA

Dashboard Principal

Visualización de métricas en tiempo real. Los indicadores de tendencia comparan el rendimiento actual con el mes anterior.

Validaciones

Control de acceso para conductores.

  • Aprobar: Otorga acceso inmediato a la app de conductor.
  • Rechazar: Bloquea el acceso. El conductor deberá contactar soporte.

Machine Learning (J48)

Modelo predictivo de satisfacción.

  • Re-entrenar: Actualiza el árbol de decisión con los últimos viajes.
  • Simulador: Permite probar escenarios hipotéticos (tarifa vs distancia).
